# Historias de Usuario - EcoPoint

1. Como ciudadano, quiero registrarme para acumular puntos por reciclar.
2. Como ciudadano, quiero iniciar sesión para acceder a mi perfil.
3. Como ciudadano, quiero ver mis puntos acumulados para saber cuánto he aportado.
4. Como operador, quiero crear puntos de reciclaje para ampliar la cobertura.
5. Como operador, quiero actualizar horarios y direcciones de puntos para informar correctamente.
6. Como ciudadano, quiero registrar entregas de residuos para ganar puntos automáticamente.
7. Como administrador, quiero mantener categorías de residuos con su puntaje por kilogramo.
8. Como ciudadano, quiero ver recompensas disponibles para canjear mis puntos.
9. Como administrador, quiero actualizar stock y costo de recompensas según demanda.
10. Como ciudadano, quiero valorar los puntos de reciclaje para mejorar la calidad del servicio.
